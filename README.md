

# QuestForge ⚔️

A Python-based framework designed for building RPG character systems, design pattern demonstrations, and simulation components.

-------------------------------------------------------------------------------------------------------------------------------

## 🏗️ Project Architecture

```text
QuestForge/
├── domain/       # Core business logic and character class hierarchies
├── patterns/     # Design pattern implementations
├── infra/        # Infrastructure and system configurations
├── tests/        # Test suites and unit tests
└── play.py       # Main entry point script
